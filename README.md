# Operation Chronos

Sitios de ciclo de Comunicar L2 (7°, Term 29) para proyectar en clase e incrustar en OPEN.

- `ciclo-1/index.html` · Cycle 1 · Code Red · Pilgrims of 1380

Cada sitio es un solo archivo HTML sin dependencias externas.

Los iframes para copiar en OPEN están en `iframes/index.html` (https://operation-chronos.vercel.app/iframes/). Al publicar un ciclo nuevo, se marca `ready: true` en la lista `CYCLES` de esa página.
