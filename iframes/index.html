Iframes para OPEN

Cada ciclo aparece aquí cuando se publica. Copie su código y péguelo en la página del ciclo en OPEN.

En OPEN:
  1. Active la edición y agregue una Página o una Etiqueta en la sección del ciclo.
  2. En el editor, abra el código HTML con el botón </>.
  3. Pegue el iframe, guarde y abra la página para revisar que se vea.
Si un ciclo cambia, el enlace sigue siendo el mismo: no hay que volver a pegar el iframe.
